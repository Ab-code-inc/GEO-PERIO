# Rights and source attribution

This repository supplies final scientific data tables and the code needed to reproduce the associated figures. It does not include source-publication PDFs, third-party software installations or a raw GEO data mirror.

GEO accession identifiers, study identifiers and publication references are retained in the scientific tables and their source documentation. Original studies and data deposits should be credited when their data or findings are reused. Public availability of a source does not itself establish unrestricted redistribution rights.

No project-specific software or data reuse licence is granted by this repository snapshot. Any rights statements supplied with individual source materials continue to apply; this repository does not replace or extend those terms.

The figure code depends on Python, Matplotlib, NumPy, pandas, SciPy, openpyxl and Pillow. These dependencies are installed separately and retain their respective licences. Arial is not bundled; the generators use an available system font or Matplotlib's DejaVu Sans fallback.
