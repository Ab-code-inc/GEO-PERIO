# GEO-PERIO

Data and analysis code for **Integrative analysis of periodontitis transcriptomes reveals shared tissue responses and limits of gene-level replication**.

GEO-PERIO integrates cohort-level replication, predictive modelling, single-cell analysis and cross-disease comparisons of periodontitis transcriptomes.

The reproducibility package is being assembled from the deposited expression data, sample metadata, literature-derived inputs and analysis scripts used in the study.
